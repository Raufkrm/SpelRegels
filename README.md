# Papa, erger je niet!

Een snelle, tweetalige Vue-website met de spelregels voor **Papa, erger je niet!**
en **Vier op een rij (5 × 5)**.

## Lokaal starten

```bash
npm install
npm run dev
```

## Publiceren op GitHub Pages

De workflow in `.github/workflows/deploy.yml` publiceert de website automatisch
wanneer er naar `main` wordt gepusht.

Activeer in GitHub onder **Settings → Pages** als bron **GitHub Actions**.
